# Shazaming_Whales
Building a convolution neural network (CNN) to classify 3 whale species given audio data collected by NOAA. Performed extensive data preprocessing and cleaning to collect and cut audio data into a usable format for the CNN. Data is acquired from [NOAA Passive Acoustic Database] (https://console.cloud.google.com/storage/browser/noaa-passive-bioacoustic/dclde/2013/nefsc_sbnms_200903_nopp6_ch10/source-audio?pageState=(%22StorageObjectListTable%22:(%22f%22:%22%255B%255D%22)))
